# 如何写学习笔记

## 笔记模板

每篇笔记按统一结构记录，直接复制下面的模板到新页面即可：

```markdown
# 章节标题

::: tip 对应教程
[章节链接](https://datawhalechina.github.io/easy-vibe/...) · 学习日期：2026-XX-XX
:::

## 🎯 学习目标

- 目标 1
- 目标 2

## 📚 核心概念

用自己的话总结这一章的关键知识点（不要照抄原文，能讲出来才算学会）。

## 💡 我的理解与思考

这一章让我联想到什么？哪里和我的经验一致/冲突？

## 💻 关键代码 / 命令

\```bash
# 值得记录的命令或代码片段
\```

## ✏️ 作业与练习

- [ ] 作业 1
- [ ] 作业 2

## ❓ 疑问清单

- 还没搞懂的问题，之后回头解决
```

## 添加新笔记的步骤

1. 在 `docs/notes/` 对应阶段目录下新建 `md` 文件（如 `docs/notes/stage1/06-new-topic.md`）
2. 复制上面的模板并填写内容
3. 在 `docs/.vitepress/config.mts` 的 `sidebar` 中注册新页面
4. 保存后浏览器自动热更新，无需重启

## 写笔记的 3 个原则

| 原则 | 说明 |
| --- | --- |
| 费曼式复述 | 用自己的话讲一遍，讲不清楚就说明还没学会 |
| 可验收 | 每条笔记尽量带上"如何验证我学会了"（作业、代码、项目） |
| 小步快跑 | 学完一小节就记，不要攒到最后一次性补 |
