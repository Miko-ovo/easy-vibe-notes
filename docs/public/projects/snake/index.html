操作说明

  • ↑↓←→ 控制方向
  • WASD 同上
  • 空格 暂停 / 继续
  • Enter 开始 / 重玩

游戏规则

  • 吃到红色食物，蛇身变长，分数 +10
  • 每吃一颗食物，速度会略微提升
  • 撞到墙壁或自己身体即游戏结束
  • 蛇无法直接反向（防止自杀）
